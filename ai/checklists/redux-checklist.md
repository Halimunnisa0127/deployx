# Redux Checklist

## Purpose

Verify Redux implementation follows project standards.

---

## State

- Redux used only for shared state.
- Local state remains local.

---

## Slice

- Existing slice reused when appropriate.
- Initial state organized.
- Reducers remain pure.

---

## Async

- AsyncThunk used where appropriate.
- Loading handled.
- Success handled.
- Error handled.

---

## Quality

- Selectors reused.
- Duplicate state avoided.

---

## Final Verification

- State flow verified.
- Redux implementation consistent.
