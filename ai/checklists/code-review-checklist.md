# Code Review Checklist

## Purpose

Review the implementation for quality, maintainability, and consistency.

---

## Architecture

- Folder structure followed.
- Existing patterns reused.
- Business logic separated from UI.
- No duplicated functionality.

---

## Code Quality

- Clear naming.
- Small focused functions.
- Reusable components.
- No dead code.
- No unused imports.

---

## Performance

- Unnecessary renders avoided.
- Duplicate API calls avoided.
- Memoization used only when beneficial.

---

## Security

- Sensitive data protected.
- Inputs validated.
- Authentication respected.

---

## Final Verification

- Code is readable.
- Code is maintainable.
- Ready for merge.
