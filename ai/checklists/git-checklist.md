# Git Checklist

## Purpose

Verify Git workflow before pushing changes.

---

## Branch

- Correct branch checked out.
- Latest changes pulled.

---

## Changes

- Only required files modified.
- Generated files excluded.
- Environment files excluded.

---

## Commit

- Meaningful commit message.
- Conventional commit format used.
- Commit focused on one logical change.

---

## Verification

- Build succeeds.
- Lint succeeds.

---

## Final Verification

- Ready to push.
- Ready to open Pull Request.
