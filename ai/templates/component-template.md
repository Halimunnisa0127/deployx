# React Component Template

## Purpose

Create reusable, maintainable, production-ready React components that follow the DeployX architecture.

---

## Before Creating

Always inspect the project.

Check whether

- Component already exists
- Similar component exists
- Shared UI component exists

Reuse existing components whenever possible.

---

## Component Structure

Imports

Props

Hooks

Handlers

Render

Export

---

## Rules

Use

- Functional Components
- React Hooks
- Tailwind CSS
- Existing UI components

Avoid

- Inline styles
- Duplicate JSX
- Hardcoded values
- Business logic inside UI

---

## State Management

Use local state only when appropriate.

Use Redux only for shared application state.

---

## Accessibility

- Semantic HTML
- Labels
- Keyboard accessibility
- ARIA attributes when required

---

## Performance

- Keep components focused.
- Split large components.
- Memoize only when beneficial.
- Lazy load large pages where appropriate.

---

## Before Completion

Verify

- Responsive
- Accessible
- Reusable
- Clean naming
- No unused imports
- No duplicated code
