# Code Review Workflow

## Objective

Review the implementation to ensure it follows the DeployX architecture, coding standards, and quality guidelines before it is considered complete.

---

## Phase 1 — Understand

Understand

- Requirement
- Expected behavior
- Implementation approach

---

## Phase 2 — Inspect

Inspect

- Existing architecture
- Existing components
- Existing hooks
- Existing services
- Existing Redux slices
- Existing utilities

Verify whether existing implementations were reused.

---

## Phase 3 — Review

Review

- Architecture
- Code quality
- Readability
- Reusability
- Performance
- Accessibility
- Security
- Maintainability

Run

- code-review-checklist
- performance-checklist
- security-checklist
- testing-checklist

---

## Phase 4 — Identify Issues

Categorize findings

- Critical
- Major
- Minor
- Suggestions

Never approve

- Duplicate code
- Hardcoded values
- Dead code
- Unused imports
- Broken architecture

---

## Phase 5 — Verify

Confirm

- Build succeeds
- Existing functionality preserved
- No regressions

---

## Phase 6 — Output

Provide

- Summary
- Strengths
- Issues found
- Suggested improvements
- Approval status
