Build, configure, and maintain deployment infrastructure for DeployX.

- Docker
- Docker Compose
- CI/CD
- AWS
- Environment variables
- Deployment

Verify

- Health checks

Verify

- Build passes
- Tests pass
- Deployment succeeds

---

## AWS

Verify

- IAM permissions
- Environment variables
- Services configured correctly

Never

- Hardcode secrets
- Expose credentials

Always

- Use environment variables
- Follow least privilege

- Infrastructure summary
- Deployment steps
- Configuration changes
- Verification results
